# front-learning
# 📚 Ma Bibliothèque — TP Front-End

Projet d'apprentissage du développement **Front-End** réalisé avec **HTML, CSS et JavaScript vanilla**.

L'objectif de ce projet est d'apprendre les bases du développement web **en pratiquant**, à travers la réalisation progressive d'une application de gestion de bibliothèque.

> ⚠️ Ce projet est un exercice d'apprentissage. Les fonctionnalités sont volontairement développées progressivement, sans utiliser de framework et sans copier une solution complète.

---

## 🎯 Objectifs

Ce projet doit permettre d'apprendre à :

* structurer une page avec **HTML5** ;
* utiliser **CSS3** pour créer une interface ;
* comprendre le **responsive design** ;
* utiliser **Flexbox** ;
* découvrir JavaScript ;
* manipuler les variables, conditions, boucles et fonctions ;
* manipuler les tableaux et objets ;
* manipuler le **DOM** ;
* gérer les événements utilisateur ;
* créer du contenu HTML dynamiquement ;
* gérer des formulaires ;
* effectuer des recherches et des filtres ;
* utiliser `localStorage` ;
* organiser un petit projet Front-End.

# 🧠 Méthode d'apprentissage

Le projet est réalisé progressivement.

Pour chaque fonctionnalité :

1. Comprendre le problème
2. Chercher les notions nécessaires
3. Consulter la documentation
4. Essayer une première solution
5. Tester
6. Corriger les erreurs
7. Refactoriser le code si nécessaire

## 🚫 Pas de copier-coller

L'objectif n'est pas d'obtenir rapidement une application fonctionnelle.

L'objectif est de comprendre **pourquoi le code fonctionne**.

En cas de blocage, privilégier cette méthode :

```text
1. Relire son code
        ↓
2. Identifier précisément le problème
        ↓
3. Chercher la notion concernée
        ↓
4. Consulter la documentation
        ↓
5. Tester une solution
        ↓
6. Demander un indice si nécessaire
```
